# Briefing

This briefing introduces the concepts behind the Patternode Knowledge Store lab, provided as open source on GitHub. It shows how an agent can answer from source content without inventing what was never said, how the usual approach fails, how graph and vector search belong together, and how to try this store on your own documents.

[Watch the briefing](media/knowledge-store-briefing-01.mp4) (about seven minutes).

The examples use three books of Sherlock Holmes stories as a stand-in for any collection. The question on screen is where Professor Moriarty appears. He appears in *The Final Problem*, and that story brings him to the Reichenbach Falls. The same story calls him a man of good birth and does not name a birthplace.

The design these pictures follow is in [Architecture](../architecture/README.md). Installing the store in your own AWS account is the [deployment guide](../deploy/aws/README.md).
